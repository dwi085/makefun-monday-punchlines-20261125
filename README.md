Entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on make.fun.

One joke about Monday mornings, at most 200 characters, judged on laughs by a pairwise judge model. The program writes the joke to `/output/entry.txt`.

> Monday doesn't knock. It walks in, sits on my calendar, and starts booking meetings before my eyes have finished loading.

## Run

```sh
node main.ts
cat /output/entry.txt
```
